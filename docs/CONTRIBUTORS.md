## How to reach us

- **Bugs & features:** [Open an issue](https://github.com/cykuza/cykuza-web/issues)
- **Code changes:** [Open a pull request](https://github.com/cykuza/cykuza-web/pulls)
- **Security reports:** see [SECURITY.md](../SECURITY.md) — do **not** file public issues that include seeds, keys, or production Electrum credentials

## Contributing

1. Fork the repository
2. Create a feature branch
3. Keep changes focused; follow existing `lib/` domain patterns (no UI-only security gates)
4. Run `npm audit --audit-level=high`, `npm run lint`, `npm test`, `npm run build`
5. Open a PR against `master`

Dependency upgrades are **manual** (no Dependabot). See [SECURITY.md](../SECURITY.md).
