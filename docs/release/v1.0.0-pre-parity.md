# Release notes — `v1.0.0-pre-parity`

**Status:** published baseline (historical)  
**Git tag:** [`v1.0.0-pre-parity`](https://github.com/cykuza/cykuza-web/releases/tag/v1.0.0-pre-parity)  
**Commit:** `8a629446a6ea9f7504509f324ed7acccce004348`  
**Published:** 2026-08-06  

This is the **last committed tree before** the W0–W7 security-parity track. It documents what cykuza-web was *before* Next 16, exact crypto pins, and domain security controls.

## What this release includes

- Non-custodial Cyberyen **explorer + hot wallet** (Next.js App Router)
- ElectrumX over WSS (browser client + API routes)
- **Typed ElectrumX protocol layer** for server routes (`lib/electrum/protocol`, `rpc`)
- Multi-server failover / tip-probe session plumbing (capability failover only — **not** dual-server fingerprint trust)
- Wallet create / import on the **legacy** crypto stack of that revision
- Session vault via browser `sessionStorage` (pre–Argon2id / pre–passphrase domain)

## Stack at this revision

| Area | Versions |
|------|----------|
| Framework | Next.js `^14.2`, React `^18.3` |
| Mnemonic | `bip39@3.1.0` |
| Keys / tx | `bip32@^4`, `bitcoinjs-lib@^6`, `ecpair@^2` |
| secp | `@bitcoinerlab/secp256k1@^1.2` (ranged) |
| Package version field | `1.0.0` |

Crypto packages were **not** exact-pinned. CI high-audit gate and W0–W7 domain controls were **not** present.

## What this release is not

- Does **not** include W0–W7 security parity (entropy modes, BIP39 passphrase, 5‑min lock, Argon2id vault, send safeguards, Electrum dual verify)
- Does **not** ship browser zip artifacts (Next source/deploy)
